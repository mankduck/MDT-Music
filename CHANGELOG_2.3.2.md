# MDT Music v2.3.2 — UI improvements

- YouTube playlist: removes the nested fixed-height ScrollView; the main page scroll handles long playlists.
- Deleted songs: full-page table with select checkbox, title/artist, individual restore, batch restore and permanent delete.
- Management menu: a rounded, theme-aware custom PopupWindow replaces the system grey PopupMenu.
- Same applicationId/database, versionCode 19.
- Maintains existing signing workflow from v2.3.1; signing secrets must be configured to produce a signed update.
- Not built or tested on a physical Android device.
